## What Was Done

### `seed_qa.py` — Created
A dedicated QA fixture script that loads 10 test scenarios on top of the base seed data:

| # | Scenario | What It Tests |
|---|----------|---------------|
| 1 | Empty Project | Empty state UI (no materials, tools, or media) |
| 2 | Exactly On Budget | Variance = $0 display |
| 3 | Over Budget | Positive variance, red highlighting, dashboard alert |
| 4 | Free Materials | $0 estimated and actual prices |
| 5 | Estimates Only | All actual prices are NULL (not yet purchased) |
| 6 | Many Items | 10 materials + 12 tools on one project |
| 7 | Mixed Tool Ownership | Same project has owned ($0) and purchased tools |
| 8 | Media with Links | Receipts linked to specific line items |
| 9 | Deep Hierarchy | 3-level parent → child → grandchild |
| 10 | Multiple Relationships | different types: similar_to, follow_up, depends_on |

### `README.md` — Updated

### How to Use
```bash
python seed.py --reset   # Load base catalog + 5 sample projects
python seed_qa.py        # Add 10 QA edge-case projects
python run.py            # Start server and test at localhost:5000
```

The script prints a URL guide showing which project ID corresponds to each scenario.
