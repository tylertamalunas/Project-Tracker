## Query Behavior Documentation
- **NULL actual_unit_price**: contributes $0 to spend (treated as "not yet purchased")
- **Zero actual_unit_price**: contributes $0 (included in sum but produces no spend — e.g., free samples)
- **already_owned = true**: excluded entirely from tool spend calculations
- **All project statuses**: included in global totals (planned, active, and completed projects all count)
