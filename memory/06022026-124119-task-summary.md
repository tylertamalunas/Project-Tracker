# Task Complete: Implement Media Links to Line Items

## Date
2026-06-02 12:41

## Task
Allow receipts or photos to be associated with a specific material or tool line item.

## What Was Done

### `app/services/media_link_service.py` — Created
- `create_link(media_id, entity_type, entity_id)` — link media to project_material or project_tool
- `get_links_for_media(media_id)` — get all links for a media record
- `get_links_for_entity(entity_type, entity_id)` — get links for a line item
- `get_media_for_entity(entity_type, entity_id)` — get Media instances for a line item
- `delete_link(link_id)` — remove a link

### Validation:
- Media must exist
- Entity type must be 'project_material' or 'project_tool'
- Entity must exist
- Media and line item must belong to the same project (cross-project rejected)
- Duplicate links prevented

### `app/routes/media.py` — Updated
- `POST /projects/<id>/media/<mid>/link` — create a link via form
- `POST /projects/<id>/media-links/<lid>/delete` — remove a link
