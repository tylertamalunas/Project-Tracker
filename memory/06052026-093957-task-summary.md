## Bug Found and Fixed

**Issue:** Deleting a Media record did NOT cascade-delete its MediaLink records. SQLAlchemy's `backref="links"` default behavior tried to SET NULL on `media_links.media_id` (a NOT NULL column), causing an IntegrityError.

**Fix:** Changed the MediaLink model's relationship from:
```python
media = db.relationship("Media", backref="links")
```
to:
```python
media = db.relationship("Media", backref=db.backref("links", cascade="all, delete-orphan"))
```

This ensures deleting a Media record automatically removes all associated media_links.
