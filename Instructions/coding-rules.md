# Coding Rules

- Make small, focused changes
- Explain what files are being changed
- Do not rewrite unrelated files
- Use simple readable code
- Prefer explicit names over clever abstractions
- Add comments only where useful
- Keep MVP simple
- All tests will be placed in "tests" folder, and will not be deleted after use. 
- After finishing all items in "current-task.md" generate a markdown file in the "memory" folder with a summary of what was done. File format is "{datetime}-task-summary.md" with {datetime} being in the format of "MMDDYYYY-HHMMSS"
- after finishing a task, add, commit, and push the changes to git repo.
